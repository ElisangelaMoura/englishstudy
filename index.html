📖 User Manual & Science of Learning

Autoria: Elisangela da Silva Moura

Objetivo: Facilitar o aprendizado de inglês através de frases, expressões e contextos retirados de filmes, livros, textos ou outras fontes, utilizando a técnica de repetição espaçada e múltipla escolha.

🎬 1. Cadastrando um Novo Tema

Para começar a estudar, você precisa criar uma "pasta" (deck) baseada em um tema (filme, livro, texto, outros):

  • Passo a passo: Vá até o menu lateral esquerdo na seção "Add New Tema".
  • Ação: Digite o nome do tema no campo de texto e clique no botão "+ Add".
  • Resultado: O tema aparecerá automaticamente logo abaixo na sua lista de decks de temas.

📝 2. Criando e Gerenciando Flashcards

Cada cartão guarda uma informação importante que você deseja memorizar.

  • Front (Frente): A palavra, expressão ou pergunta em inglês (ex: "Piece of cake").
  • Back (Verso): A explicação ou tradução em português (ex: "Muito fácil, moleza").
  • Exercise (Opcional): Uma frase de exemplo aplicando o termo.
  • Opções A, B, C, D (Opcional): Alternativas para criar um quiz de múltipla escolha.
  • Correct Option: Selecione qual das letras é a resposta certa.
  • Image Link (Opcional): Cole o link de uma imagem da internet para ilustrar o cartão.

🔄 3. Usando e Estudando com o Sistema

  • Virar o cartão: Clique no botão "🔄 Flip Card" ou diretamente sobre o cartão para ver a resposta no verso e testar os exercícios.
  • Ouvir a pronúncia: Clique no ícone 🔊 para escutar a pronúncia nativa em inglês.
  • Navegação: Use os botões "Previous" e "Next".

📅 4. Revisão Espaçada (Spaced Review)

Use os botões de arquivo inferior para enviar cartões para:

  • 📅 Next Week: Para revisar na próxima semana.
  • 🗓️ Next Month: Para revisar no próximo mês.
  • 🔄 From Time to Time: Para revisões esporádicas.

💡 Dicas de Ouro para Estudos Eficientes

  • Seja Direto na Frente: Coloque apenas uma palavra ou expressão curta.
  • Contextualize: Adicione frases reais de filmes, livros ou textos.
  • Use Imagens: Ajudam na memorização visual rápida.

🧠 O Poder da Repetição Espaçada: O que a Ciência aponta

A Repetição Espaçada é comprovada pela psicologia cognitiva e neurociência:

  • Curva do Esquecimento de Ebbinghaus: O cérebro descarta informações se não revisitadas. A repetição reinicia a curva e fortalece conexões neurais.
  • Spacing Effect: Distribuir sessões ao longo do tempo supera drasticamente o estudo concentrado de última hora.
  • Recuperação Ativa: O esforço do cérebro para resgatar a resposta ao virar o cartão torna o aprendizado sólido.
